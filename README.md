# KBO 프로야구 일별 승부 예측 분석

KBO 리그 경기 데이터를 실시간으로 수집하고, 몬테카를로 시뮬레이션을 통해 각 경기의 승패 확률을 예측하는 웹 애플리케이션입니다.

---

## 기술 스택

| 구분 | 사용 기술 |
|------|-----------|
| 백엔드 | Python 3.9, Flask, SQLAlchemy |
| 데이터베이스 | SQLite |
| 시뮬레이션 | NumPy (포아송 분포) |
| AI 분석 | Anthropic Claude API (claude-sonnet-4-6) |
| 데이터 수집 | requests + 정규표현식 HTML 파싱 |

---


## 시뮬레이션 방식

### 개요

포아송 분포 기반 **몬테카를로 시뮬레이션** 10,000회를 실행하여 각 팀의 기대 득점(λ)을 추정하고, 득점 분포에서 승패 확률을 도출합니다.

```
numpy.random.poisson(λ_away, 10_000)  →  원정 팀 득점 분포
numpy.random.poisson(λ_home, 10_000)  →  홈 팀 득점 분포

away_wins = Σ(원정득점 > 홈득점) + 동점 × 0.5
home_wins = Σ(홈득점 > 원정득점) + 동점 × 0.5
```

---

## λ (기대 득점) 계산 방법

각 팀의 λ는 **시즌 평균 경기당 득점**을 기준으로 여러 보정 계수를 곱해 산출합니다.

```
λ_away = 원정팀_RPG × ERA계수 × 최근흐름 × 원정전적계수 × 위험타자계수 × 맞대결계수 × 파크팩터 × 홈불펜WAR계수
λ_home = 홈팀_RPG  × ERA계수 × 최근흐름 × 홈전적계수   × 위험타자계수 × 맞대결계수 × 홈어드밴티지(1.04) × 파크팩터 × 원정불펜WAR계수
```

λ는 최소 2.0, 최대 10.0으로 클램핑됩니다.

> **파크팩터**는 두 λ에 동일하게 곱해 구장 특성을 반영합니다.  
> **불펜WAR계수**는 상대 팀의 불펜 전력을 반영합니다 (홈 불펜이 강할수록 원정팀 λ 감소).

---

### 각 계수 상세

#### 1. ERA 계수 (선발 투수 지배력)

상대 선발 투수의 ERA로 자 팀의 득점 기대값을 조정합니다.

```
ERA계수 = ERA / 리그평균ERA(4.50)
범위: [0.55, 1.75] 클램핑
```

예) 상대 선발 ERA 2.25 → 계수 0.55 (득점 45% 억제)  
예) 상대 선발 ERA 6.75 → 계수 1.50 (득점 50% 증가)

**시즌 ERA + H2H ERA 블렌딩:**  
상대전적 ERA는 샘플이 적어 과가중을 피하기 위해 아래 비율로 혼합합니다.

```
# 통산 경기 수에 따라 H2H 가중치 상향
H2H_가중치 = 0.35 (5경기 이상) / 0.25 (5경기 미만)
ERA계수(최종) = 시즌ERA계수 × (1 - H2H_가중치) + H2H_ERA계수 × H2H_가중치
```

H2H 데이터가 없을 경우 시즌 ERA만 사용합니다.

#### 7. 통산 상대팀 승률 계수 (상성)

투수의 특정 팀 상대 **통산 승률**로 λ를 추가 보정합니다. 특정 팀에 유독 강하거나 약한 패턴을 반영합니다.

```
상성계수 = 1.0 - (통산승률 - 0.5) × 0.20 × 샘플가중치
샘플가중치 = min(1.0, 통산경기수 / 15)   # 15경기 이상이면 full weight
범위: [0.93, 1.07] (최대 ±7% 조정)
```

- 투수 통산 승률 70%, 15경기 → 계수 0.94 (상대팀 득점 6% 억제)
- 투수 통산 승률 20%, 10경기 → 계수 1.04 (상대팀 득점 4% 증가)
- **3경기 미만은 샘플 부족으로 무시**

```
λ_home = ... × 통산상성계수(원정투수 vs 홈팀)
λ_away = ... × 통산상성계수(홈투수 vs 원정팀)
```

#### 2. 최근 흐름 (연속 기록)

연승/연패 기록으로 팀의 현재 모멘텀을 반영합니다.

```
흐름계수 = 1.0 + min(|연속수|, 5) × 0.015 × 방향(+1/-1)
```

예) 5연승 → 1.075 / 5연패 → 0.925 / 연속기록 없음 → 1.0

#### 3. 홈/원정 전적 계수

해당 시즌의 실제 홈·원정 승률을 반영합니다.

```
홈전적계수 = 홈승률 / 0.500
원정전적계수 = 원정승률 / 0.500
범위: [0.7, 1.3] 클램핑
```

#### 4. 위험 타자 OPS 계수

상대 선발 투수를 상대로 강한 타자 상위 5명의 평균 OPS로 공격력을 보정합니다.

```
위험타자계수 = 1.0 + (평균OPS / 리그평균OPS(0.750) - 1.0) × 0.25
범위: [0.90, 1.15] 클램핑
```

#### 5. 최근 맞대결 계수

해당 시즌 두 팀의 직접 대결 전적 비율을 반영합니다.

```
맞대결계수 = (맞대결승수 / 총맞대결수) / 0.5
범위: [0.92, 1.08] 클램핑
```

#### 6. 홈 어드밴티지

홈 팀 λ에 고정 계수 **1.04** 적용 (KBO 리그 홈 팀 평균 승률 약 52~54% 기반).

#### 8. 파크팩터 (구장 특성)

KBO 10개 구장별 고정 파크팩터를 적용합니다. 1.0 초과는 타자 친화 구장, 미만은 투수 친화 구장입니다.

```
파크팩터 = PARK_FACTORS[홈팀]   # 아래 테이블 참고
범위: [0.90, 1.10]
```

| 홈팀 | 구장 | 파크팩터 |
|------|------|---------|
| LG / 두산 | 잠실 | 1.05 |
| 한화 | 대전 한화생명이글스파크 | 1.02 |
| KIA | 광주 챔피언스필드 | 1.01 |
| 롯데 | 부산 사직구장 | 1.00 |
| 삼성 | 대구 라이온즈파크 | 0.97 |
| SSG | 인천 SSG 랜더스필드 | 0.97 |
| 키움 | 서울 고척 스카이돔 | 0.96 |
| NC | 창원 NC파크 | 0.95 |
| KT | 수원 KT 위즈파크 | 0.93 |

파크팩터는 원정·홈 두 팀의 λ에 **동일하게** 적용됩니다 (구장이 양 팀에 동등하게 영향).

#### 9. 불펜 WAR 계수

statiz 팀 전력 비교에서 수집한 **불펜WAR**을 리그 평균(3.0)과 비교해 λ를 보정합니다.

```
불펜WAR계수 = 1.0 - (불펜WAR - 리그평균(3.0)) / 리그평균 × 0.25
범위: [0.92, 1.08] 클램핑   (최대 ±8% 조정)
```

- **홈 팀 불펜WAR 높음** → `λ_away` 감소 (홈 불펜이 원정 타선을 막음)  
- **원정 팀 불펜WAR 높음** → `λ_home` 감소  
- 불펜WAR 데이터 없을 경우 계수 = 1.0

## 시뮬레이션 출력 (추가 지표)

### 득점 범위 (25~75% 분위수)

10,000회 시뮬레이션 결과에서 **25·50·75 퍼센타일**을 계산해 예상 득점 범위를 제공합니다.

```python
p25, median, p75 = np.percentile(scores, [25, 50, 75])
# 표시: "3~7점" (p25~p75)
```

### 선발 투수 제구·탈삼진 지표

statiz 피안타율·탈삼진·볼넷·이닝 데이터로 K/9, BB/9, K-BB/9을 산출합니다.

| 지표 | 계산식 | 의미 |
|------|--------|------|
| K/9 | 탈삼진 / 이닝 × 9 | 9이닝당 탈삼진 수 |
| BB/9 | 볼넷 / 이닝 × 9 | 9이닝당 볼넷 허용 수 |
| K-BB/9 | (탈삼진 - 볼넷) / 이닝 × 9 | 제구+구위 종합 지표 (높을수록 우수) |

> K-BB/9 ≥ 3.0: 우수 선발 투수 기준선 (시뮬레이션 화면에서 하이라이트 표시)

## 최종 승률 산출

몬테카를로 결과에 최근 10경기 흐름을 30% 블렌딩합니다.

```
최종승률(원정) = 시뮬레이션승률 × 0.70 + 최근10경기승률 × 0.30
최종승률(홈)   = 100 - 최종승률(원정)
```

최근 10경기 비율은 두 팀의 최근 10경기 승수 합 대비 각 팀 승수의 비율로 산출됩니다.

## 경기 결과 자동 분석 (Post-Game Analysis)

스크래핑으로 새 경기 결과가 들어올 때마다 **예측 vs 실제**를 자동 비교 분석합니다.

### 동작 흐름

```
admin/scrape 실행
  └─ 새 RecentGame 저장
       └─ TodayGame (선발 투수/스탯) + 경기 전 TeamStat 스냅샷으로 시뮬레이션 재현
            └─ 예측 승팀, 확신도, 핵심 데이터 저장
                 └─ 예측 정확도 분석 텍스트 생성 → result_analysis 저장
```

### 예측 적중 시 분석 항목

| 항목 | 내용 |
|------|------|
| 예측 득점 정확도 | λ 예측값 vs 실제 스코어 오차 |
| 적중 기여 요인 | 몇 개 요인 중 몇 개가 실제 결과와 일치했는지 |
| 통산 상성 적중 | 투수 상성 데이터가 이번에도 유효했는지 확인 |
| 핵심 적중 포인트 | 가장 결정적이었던 요인 1개 강조 |

### 예측 빗나감 시 분석 항목

| 항목 | 내용 |
|------|------|
| 예측 득점 정확도 | λ 예측값 vs 실제 스코어 오차 |
| 빗나간 원인 분석 | 타선 폭발 / 투수 부진 / 상성 역전 등 자동 감지 |
| 다음 시뮬레이션 주목 포인트 | 이 매치업에서 앞으로 더 주목해야 할 변수 |
| 시뮬레이션 개선 제안 | 불펜 가중치, 상성 데이터 분리 등 학습 기반 제안 |

### 화면 표시

- **홈 화면** 최근 경기 카드: ✅ 적중 / ❌ 빗나감 배지 + 예측팀/확신도
- **경기 상세 페이지**: 마크다운 렌더링된 전체 분석 섹션

### 분석 생성 방식

`ANTHROPIC_API_KEY` 설정 시 Claude API로 서술형 분석 생성, 미설정 시 규칙 기반 fallback 자동 적용.

## 분석 텍스트 생성

### Claude API 사용 시 (`ANTHROPIC_API_KEY` 환경변수 설정)

시뮬레이션 결과, 선발 투수 스탯, 위험 타자, 팀 전력 데이터를 프롬프트로 구성하여 **claude-sonnet-4-6** 모델에 전달합니다. 분석 항목:

- 핵심 포인트 3가지
- 선발 투수 분석 (시즌 스탯 + 통산 상대팀 ERA/OOPS/승률 + 상성 패턴)
- 위협 타자 분석
- 팀 흐름 및 전력 비교 (WAR, 최근 맞대결)
- 승부 포인트
- 최종 예측 및 예상 스코어

### API 키 미설정 시 (규칙 기반 fallback)

동일한 데이터를 기반으로 규칙 기반 텍스트를 자동 생성합니다. ERA 차이, OPS 임계값, WAR 차이 등 사전 정의된 기준으로 분석 텍스트를 조합합니다.

| 경로 | 설명 |

## 경기 상세 페이지 (`/game/...`)

완료된 경기를 클릭하면 KBO 공식 API에서 박스스코어를 실시간으로 가져와 표시합니다.

### 표시 항목

| 섹션 | 내용 |
|------|------|
| 경기 헤더 | 날짜, 구장, 최종 스코어, 승리·패전·세이브 투수 |
| 경기 특이사항 | 결승타, 홈런, 2루타 등 주요 장면 |
| 타자 성적 | 원정·홈 각각 — 타순, 포지션, 이닝별 타격, 타수/안타/타점/득점/타율 |
| 투수 성적 | 원정·홈 각각 — 이닝, 피안타, 탈삼진, 볼넷, 실점, 자책, 결과(승/패/세/홀) |

### 취소·미완료 처리

경기가 취소되었거나 아직 결과가 없으면 박스스코어 대신 안내 메시지를 표시합니다.

### 데이터 출처

KBO 공식 웹서비스 (`koreabaseball.com/ws/Schedule.asmx/GetBoxScore`)를 POST 요청으로 호출합니다. 별도 저장 없이 매 조회 시 실시간으로 파싱합니다.

## 정적 블로그 (GitHub Pages)

`build_blog.py` 를 실행하면 시뮬레이션 결과를 정적 HTML 블로그로 생성하고 GitHub Pages에 자동 배포합니다.

**블로그 주소:** [https://namjinwoo.github.io/kbo/](https://namjinwoo.github.io/kbo/)

### 블로그 탭 구성

| 탭 | 내용 |
|---|---|
| 오늘 경기 분석 | 날짜별 완료 경기 목록 → 경기 카드 (예측 적중 여부, 승률 바, 위협 타자, 분석 텍스트, 박스스코어) |
| 다음 경기 예상 | 날짜별 예정 경기 목록 → 경기 카드 (선발 투수 ERA, 승률 바, 기대득점 λ, 위협 타자, 분석 텍스트) |
| 소개 | 이 README 문서 전체를 블로그 내에서 렌더링 |

### 경기 카드 상세 (오늘 경기 분석)

| 섹션 | 내용 |
|---|---|
| 매치업 헤더 | 최종 스코어, 예측 적중·빗나감 뱃지 |
| 승패 투수 | 승리·세이브·패전 투수 태그 |
| 승률 바 | 사전 시뮬레이션 기반 원정/홈 승률 |
| 위협 타자 | 선발 투수 상대 강타자 OPS |
| **예측 vs 결과 분석** | **✅/❌ 적중 여부, 득점 오차, 빗나간 원인 분석 — 항상 노출** |
| 경기 결과 상세 | KBO 공식 박스스코어 — 타자 이닝별 기록 + 투수 성적표 (아코디언) |

## 시뮬레이션 한계 및 유의사항

- 부상, 날씨, 컨디션 등 비정형 변수는 반영되지 않습니다.
- H2H 샘플 크기가 작을 경우 해당 계수의 신뢰도가 낮습니다.
- 선발 투수 미정 경기는 ERA 계수를 1.0(리그 평균)으로 처리합니다.
- 본 예측은 통계적 참고 자료이며, 투자·도박 목적으로 사용하지 마십시오.
